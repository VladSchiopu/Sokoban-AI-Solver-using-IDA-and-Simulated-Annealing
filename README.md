To run the project, you should first create a Python virtual environment, activate it, and install the necessary libraries. 
After that, you can open and run the main.ipynb Jupyter Notebook, which allows you to load maps, run the solvers, and visualize results. 
The project includes 9 test maps in YAML format, ranging from easy to very hard, and you can also create your own maps following the same format. 
Additionally, the repository contains a PDF report that analyzes and compares the performance of the two algorithms based on multiple criteria such as execution time, number of explored states, and quality of the solution.
